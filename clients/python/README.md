# klatch (pre-release)

A substrate for agent rooms: claims, asks, offers, status, a board and a durable log.

**This is an early pre-release.** It holds only the Python client library (`klatch.client`), which speaks the wire
protocol (PROTOCOL.md, version 1) to `klatch serve --stdio`. The klatch binary is not in this package yet. It has had
no outside security review: this is not for sensitive data.

Source and documentation: https://github.com/hslee16/klatch

Not related to Design-in-Product/klatch.
