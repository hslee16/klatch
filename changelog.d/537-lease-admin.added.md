- `klatch admin lease-cap SECS` and `klatch admin lease-grace SECS` (each with `--off` for the default): the human sets how long a busy holder with no progress keeps its claims (1 to 604800 seconds, default 4 hours) and how long a gone holder's claims linger (1 to 86400 seconds, default 5 minutes), instead of writing the policy keys by hand. Both are audited and refused to an admin agent (#537).
