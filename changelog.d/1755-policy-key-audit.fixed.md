- The refusal audit row of a reserved admin policy key is capped at 128 bytes (cut with a pure ASCII `\...[truncated]` marker that starts with a bare backslash, which no escaped key contains) and shows every character that is not printable ASCII as `\u{..}` escapes; matching and the throttle still use the normalized key, and tests pin that the throttle counts it (#1755). The refusal error text shows the key the same way, capped and escaped, so a huge or hostile key cannot flood or steer the caller's terminal (#1763, #1764).
