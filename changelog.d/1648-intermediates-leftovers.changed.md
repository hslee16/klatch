- `klatch-server https --tls-client-intermediates`: an intermediates file certificate with an empty subject is refused at start (a CA subject is non-empty, so an empty one let a CRL with an empty issuer pass), and a CRL whose issuer is a listed certificate but whose signature does not verify against that certificate's key is refused at start instead of locking that issuer's clients out at handshake time (a sanity check; the certificates are still never trust anchors). The refusal for a group- or other-writable intermediates file no longer says the writer chooses who may connect.
