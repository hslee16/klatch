- The three client libraries can send the wire `read` params `max_messages` and `max_bytes` (#1390): Python `read(room, peek, max_messages, max_bytes)`, TypeScript `read(room, peek, { maxMessages, maxBytes })` and Rust `Client::read_bounded(ReadRequest::new(room).max_messages(n).max_bytes(n))`. Each library also has a call that returns the whole answer, with `omitted` (the number of messages a bounded read left unread, none when no bound was given) and `by_importance`: Python `read_bounded`, TypeScript `readBounded`, Rust `read_bounded` (returns `BoundedRead`). The values are sent as given and the server stays the authority on them. The existing `read` signatures are unchanged in all three. The Rust `ClaimRequest` gains `shared` (`ClaimRequest::new(room, path).shared(true)`), which the wire `claim` always took; the Python and TypeScript `claim` already sent it. The gaps recorded for these in `proto/wire/methods.json` are gone (#1565).
