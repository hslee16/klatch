- Forged but well-formed registry records for pids that do not run can no longer push a running session out of the listing the lease source reads: when the process table is readable, records of running pids are read first, then the newest (an unreadable table changes nothing, and a member is still never treated as dead for a record that is not found). A modification time up to a day in the future (a clock stepped back) counts as now instead of the oldest; further ahead still counts as the oldest. Record names are canonical, so `05000.json` is no longer filed under pid 5000 beside `5000.json` and the Codex prune only ever removes the exact `<pid>.json`. A same-user file can still fill the bound with forged records of pids that do run; `klatch sessions` and `klatch doctor` do not yet rank by liveness (#1692).
