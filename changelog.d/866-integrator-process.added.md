- `proto/scripts/integrator`, the integrator process for the merge queue: run by a member with the `integrator` role, outside the klatch binary and with its own `gh` and `git` login, it is woken by `ready:` words, takes the `merge:main` claim, takes its events from `gh webhook forward` (plus a periodic read of the open PR list and each PR's mergeable state), and per queued PR checks for a conflict, merges main into the branch, runs the gate, pushes, waits for green checks on the current head, merges, and posts `integrating:`, `checking:`, `merged:` or `dropped:` as fixed templates (#866). See `proto/scripts/INTEGRATOR.md`.
