- `klatch who` shows each member's last reported permission mode and the wake path it implies (`mode: bypassPermissions (wake: hook)`, `mode: default (wake: nudge)`, `mode: unknown (wake: hook)`). A member that bypasses permission prompts, or has reported no mode, is woken by its hooks and the wake watcher and never counted on for a socket nudge, and an ask's poster is told which present members get no nudge for that reason (#677).
