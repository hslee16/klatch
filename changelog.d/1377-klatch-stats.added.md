- `klatch admin stats [--room ROOM] [--since YYYY-MM-DD] [--top N] [--json]` prints a counts-only usage report: messages per room and day, senders and attribution, message kinds, asks (created, answered, closed, median and p90 time to a first answer), claims by class (file, ticket, ask, other, by name prefix), claim notes, live claims, members waiting on a claim, refusals by rule, direct message and private room counts, members (joined, never posted, marked done, muted, with a parent), hook runs by event, admin acts by name and worker credential counts. It never prints a message body, ask text, claim reason or note, label or payload, and a sealed label is counted and never opened. It is an admin read act (the passphrase at the terminal, standard output must be the controlling terminal, one audit row) because the counts name who talked in which room. No schema change (#1377, #1362).
