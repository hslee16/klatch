- Shell scripts that run under `set -o pipefail` no longer pipe into an early-exit consumer (`grep -q`, `grep -m1`, `head -1`, `head -n 1`) in 111 places; under CPU load the producer could die of SIGPIPE and fail the check although the consumer matched (#1357). A new `release/check-sigpipe.sh`, run by the gate, fails when the pattern comes back; a reviewed exception carries `# sigpipe-ok: <reason>`.
