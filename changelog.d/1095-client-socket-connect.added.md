- The Python, TypeScript and Rust client libraries connect to the klatch-server daemon over its Unix socket with an identity (a typed name, a credential, or none): `Client.connect_socket`, `Client.connectSocket`, `Client::connect_socket` (Rust feature `client-socket`, off by default, so the `klatch` binary has no socket code). The conformance scenario of each library runs over the daemon as well as over stdio (#1095).
