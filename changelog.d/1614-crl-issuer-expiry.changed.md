- `klatch-server https --tls-client-crl FILE` now reads each CRL's times at start: a CRL with no `nextUpdate` (the verifier cannot use one), a time before 1970 or a malformed time stops the server in words; a CRL already expired, due within 7 days, or whose issuer matches no CA of the `--tls-client-ca` file (it then applies only to clients that present an intermediate CA of that name) draws a warning in the start log and the server still starts (expiry stays enforced). Uses a small bounded DER reader, no new dependency (#1614, refs #1491, #1622).
