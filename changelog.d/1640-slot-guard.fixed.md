- `klatch-server http`, `https` and `daemon` give back the global `--max-connections` slot of a connection whose handler panics (the slot is a guard freed on every way out, including an unwind), and the panic no longer ends the accept loop: it is caught, one fixed line `klatch-server: handler panicked` is logged (no data), and the server goes on. Before, one panic kept a slot for good, so repeated panics left a server that refused everything (#1640).
