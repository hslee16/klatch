- `proto/scripts/pr-sweep`: one pass of a standing PR sweep for a /loop job. It reruns cancelled jobs, integrates a behind PR on a throwaway branch, merges a PR only when every check on its latest head is green, benches the merge, closes the ticket, and posts what it will not touch (red checks, code conflicts, no ticket, stuck, abandoned) to the lobby. `pr-ledger` gains `--only N,N` (#706).
