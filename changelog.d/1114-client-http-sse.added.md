- The Python and TypeScript client libraries connect to `klatch-server http` over HTTP and server-sent events with a worker credential: `Client.connect_http(url, member=, token=)` and `Client.connectHttp(url, { member, token })`, loopback urls only. A stream that drops is reopened and every subscribed room is resubscribed from the last `seq` seen, so messages resume without a gap or a repeat (#1114). The Rust client is #1122.
