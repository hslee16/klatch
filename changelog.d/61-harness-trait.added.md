- `klatch admin room-require ROOM MODE:CAP[,CAP...]`: a room can require harness capabilities (`context-injection`, `session-identity`, `wake`, `pre-action-enforcement`, `permission-mode`, `headless-worker`, `pull-path`). With `refuse` a member whose harness lacks one cannot join; with `flag` it joins and the gap is recorded in the refusals log. Only native support counts and an unknown capability fails closed. The `Harness` trait has the Claude Code hook tier, a paper Codex adapter and the generic floor; a plain join is the floor, so it is refused by a room that requires more (#61).
