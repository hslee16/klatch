- gh-watch can post GitHub events into a separate feed room (#1404). `gh-watch serve --feed-room feed` (with `--klatch-bin`, `--as-member`) posts a PR opened, ready for review, merged, checks failed and main red as one-line data posts into the room `feed`, never the lobby, bounded by a dedupe of the same PR and state (once an hour) and `--feed-rate` (12 a minute), with every payload field cleaned and stripped of `@`. A new seat in the room named `feed` starts muted, so a member's digest, `wait`, `wake` and SessionStart briefing carry a feed line only when it mentions the member; `klatch read feed` shows it and `klatch unmute feed` is the coordinator's opt in. The builder brief tells agents not to post GitHub events by hand.
