- The recovery attempts file (`<store>.recovery-fails`, #1281) is opened without following a symlink and without blocking on a pipe, at most 64 KiB of it is read (a file over that, or one that is not a regular file, is a wait and never a free attempt), and the check and the append happen under one lock, so racing callers at the moment one attempt is due get exactly one. A recorded time of `i64::MAX` no longer wraps in release builds and grants a free attempt. `klatch doctor` warns with the count of recorded, unsettled attempts, and a wrong recovery code prints the count and the file on stderr (#1636).
