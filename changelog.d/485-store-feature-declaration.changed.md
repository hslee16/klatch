- A store backend must now declare which optional feature groups it keeps (`RoomStore::features`, no default): sessions, member notes, mute, pruning, wait positions, claim notes, anchors, claim lifecycle, asks, reviews and credentials. The gateway refuses a store that does not declare them all, and the conformance suite runs the tests of every declared feature, so a backend can no longer skip a feature quietly. SQLite declares all of them and behaves as before (#485).
