- Admin passphrase (#1233): `klatch admin init-passphrase` sets a passphrase (an Argon2id verifier in policy, never the passphrase). Every `klatch admin` command, every launcher command (`worker`, `anchor`, `run`, `judge`) and every keystore act (`recovery`, `recover`, `seal-label`, `rotate-key`, `rotate-label-key`, `backup`, `restore`, `run-archive`, `retention`, `archive`, `restore-archive`, `archives`, `export`) now asks for it at a real terminal (echo off; never from the environment, an argument or a pipe), is rate limited after three wrong ones (audited by count only), and runs as the principal `human`. New commands: `klatch admin reset-passphrase` (the recovery code sets a new passphrase), `klatch admin unlock-window` and `klatch admin shell` (one passphrase, held in that process's memory for a few minutes, for admin, worker, anchor, run and judge commands).
