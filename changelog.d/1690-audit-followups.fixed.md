- Audit rows for ignored forwarded headers never show a name above the row's requests. A name held back by a half counted request moves to a later row only once requests arrive without it, so the rows are a lower bound for a name over a whole run (behind a proxy where every request carries a header, a backlog of one never drains); the shutdown summary line prints the true whole-run total. The server's live line and summary go through one output writer, so a closed stderr cannot end the periodic rows (#1690).
- `flat()` turns every line separator and control character (CR, LF, U+0085, U+2028, U+2029, escape codes, tabs) into a space. Listings in `klatch admin audit` and `role act audit` show details that way, the audit rows themselves are unchanged, but a release note is passed through `flat()` before it is stored, so those characters in a release note are now stored as spaces (#1690).
