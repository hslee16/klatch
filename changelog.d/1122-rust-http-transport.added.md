- The Rust client connects to `klatch-server http` with `Client::connect_http` (bearer credential and member header, server-sent events, reconnect and resubscribe from the last seq, loopback urls only), behind the off-by-default `client-http` feature of `klatch`, so the `klatch` binary still has no network socket type. The conformance scenario runs over HTTP in `proto/klatch-server/tests/client_http.rs` (#1122).
