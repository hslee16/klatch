- `klatch-bench store-stats --home DIR --key-dir DIR [--json]` prints the counts-only usage report of a benchmark run store (the report `klatch admin stats --json` prints, from the same library function) without the admin passphrase; it is in the bench crate and not the shipped binary, and refuses the live store and a key directory that is not mode 700. The coordbench harness calls it after each K-arm run, writes `artifacts.store_export`, and fills `claim_conflicts`, the claim and ask counts, members who never read and hook bytes, with the ask counts cross-checked against the streams. No schema change (#1433, #1362).
