- `klatch-server https`: the client CA file and the server certificate file are now opened like the key and CRL files (no symbolic link, no FIFO, a regular file of at most 4 MiB), at start and at reload (#1492). The client CA file must also be owned by the server's user or root and not writable by group or other. A symlinked CA file or certificate is now refused: name the real file.
