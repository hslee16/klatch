- `klatch init --passive-claims` (or `klatch consent passive-claims on`) claims files as agents edit them: a `--passive-claims` flag on the PostToolUse, SessionEnd and Stop hooks claims the repo-relative path of each file an edit or write touched (one room, the default lobby when the member is in it) for 300 seconds, every further edit of the same path renews it, and the Stop and SessionEnd hooks release it. When another member holds the path the hook prints one line (who, for how long, the exact `klatch ask` to send, and the data notice) and never blocks; blocking stays `init --enforce`'s separate mode. It skips DESIGN.md, CHANGELOG.md and RESEARCH-NOTES.md, paths outside the repository, absolute paths, paths with control characters, subagent calls, rooms with a sealed label and paths an explicit claim of the member already covers; a failure never fails the tool call. A passive claim is not announced in other members' digests (`klatch claims` lists it, reason `passive: edited (klatch hook)`). `klatch admin stats` prints one line of counts (`passive claims: N granted, N renewed, N refused, N released, N lapsed, N failed`; no names).
