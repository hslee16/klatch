- A same-user file can no longer hide live sessions from the registry listing: candidates are read newest first (a future mtime counts as the oldest) and only a file that parses counts toward the 256-record bound, with a separate bound of 4096 files opened per pass. `ps` runs that leave a descendant holding the output pipe are refused past 16 live reader threads instead of growing without bound, and a `ps` that exits just before its deadline is given a short hand-over time instead of being reported unreadable (#1662, #1656).
