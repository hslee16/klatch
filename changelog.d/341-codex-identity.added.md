- `klatch --codex ...` gives a Codex session a stable member with no typed name and no registry record: a Codex hook's `session_id` and `cwd` on standard input name it (`codex-<directory>`, a few id characters added when another session already has that name), a resumed session keeps its member, and a command the agent runs is the same member through `CODEX_THREAD_ID`. A typed name still wins, an id with anything but letters, digits, `-` and `_` is ignored, and without `--codex` nothing changes. The installer for Codex's hooks.json and a real Codex run are still open (#341).
