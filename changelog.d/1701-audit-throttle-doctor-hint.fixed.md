- Refused writes to the admin passphrase keys: the one-row-a-minute audit throttle now also counts rows still queued inside an open transaction (a thousand refusals in one transaction left a thousand rows), caps a key family (`admin-unlock-*`, `admin-passphrase*`) at eight rows a minute so changing the key name does not get past it, ignores rows stamped in the future after a clock step backwards, and counts every refusal it leaves unwritten in the dropped-rows counter (#1701).
- `klatch doctor`: the "wrong key" hint is shown only when SQLite says "not a database"; a store it cannot open for another reason (permissions, a lock) says so and points at the file instead. The read-only probe of the policy table waits up to a second for a writer. The docs no longer claim a read-only open creates nothing: SQLite makes `-wal` and `-shm` beside a WAL store it reads (#1701).
