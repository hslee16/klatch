- `klatch-server https --tls-client-crl FILE` (PEM, one or more CRLs signed by the client CA, read at start): a client certificate whose serial is listed is refused at the handshake on every route (a fatal TLS alert, no HTTP, no session); a CRL file that is missing, a link, writable by group or other, empty, not PEM or holding no CRL stops the server before it listens, and the option needs `--tls-client-ca`. An expired CRL is enforced (it refuses its issuer's certificates until the file is replaced and the server restarted; the log says so at start and at each refusal) and a certificate no CRL covers is allowed. Reload without a restart is #1492 (#1491, refs #108, #157).
