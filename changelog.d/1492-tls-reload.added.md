- `klatch-server https`: SIGHUP re-reads the server certificate and key, the client CA file and the client CRL file with the checks of start, and swaps in the new TLS configuration only if all of them pass (#1492). New connections use it; open connections are not cut. On any failure the old configuration stays and one fixed line names the kind of failure. Signals are coalesced and the build is bounded. The plain `http` server now survives SIGHUP instead of exiting (a foreground `http` server survives closing its terminal and keeps its port). A reload refuses a CRL file that has expired while the CRL in force has not (ALERT line).
