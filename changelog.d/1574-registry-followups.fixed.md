- A registry directory with junk or many stale records no longer hides a live session: only record-looking names count toward the 256 bound, and with more records than the bound the newest are read (both the Claude registry and the Codex registry); a duplicate pid makes the process table unreadable; a child of `ps` that keeps the output pipe open can no longer defeat the 5 second timeout; `klatch doctor` says when no `ps` is at a fixed place; `KLATCH_TEST_PS` needs `KLATCH_TEST_SEAMS` too, so a debug binary does not read it by default (#1574, #1629).
