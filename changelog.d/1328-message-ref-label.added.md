- An ask ref of kind `message` is now checked against the label: the store answers a message id with its room (a read only, an error from a store that cannot, and the id is folded to upper case first), and the ask label must cover that room, as for `room` and `ask` refs (#1328). An unknown id is accepted like a missing room, so a refusal tells an asker only that a message with that id exists above the label (ids are guessable and the check is not yet throttled; ordering is a separate change); a `run` ref has no room and stays shape only.
