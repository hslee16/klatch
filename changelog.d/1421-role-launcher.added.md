- The coordination bench harness can start role members: arm K3 starts an integrator and a supervisor beside the workers (each its own agent process, granted in the run store through the same pseudo-terminal admin path the bench uses, never the live store), and the new arm B1-roles starts the same two roles natively with messages and the board. Each role member has its own spend cap, model and cost line in the run record (`roles`, `spend.roles_usd`), also inside the team total and the per-run and suite caps; a failed role member is recorded and does not invalidate the run, and the supervisor can ask the harness to start a replacement for a worker that stopped (#1421).
