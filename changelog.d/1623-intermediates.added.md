- `klatch-server https --tls-client-intermediates FILE` (needs `--tls-client-ca` and `--tls-client-crl`): the strict option for CRL issuers. PEM certificates whose subject names are used only to match CRL issuers, at start and at SIGHUP reload; they are never trust anchors and never used to build or verify a client chain. With it, a CRL whose issuer matches neither a CA of the client CA file nor a listed certificate is refused at start (a reload keeps the old configuration); without it that stays a warning. The file gets the checks of the CA file and is read by a bounded DER reader, no new dependency (#1623, refs #1614, #1625).
