Arm B0. The only thing you share with the other agents is the repository on `origin`. You have no messaging, no task board
and no other tool that connects you to them. Use it the way a careful team that cannot talk would.

Telling others what you are doing: you can only say it through the repository. A commit message, a branch name or a file
that you add and push is visible to everyone who runs `git fetch origin`. Nobody will look unless they choose to, so read
`git log origin/main` yourself before you start work and again before you publish.

Not stepping on each other's work: nothing stops two agents editing the same file. Before you edit a file, run
`git fetch origin` and `git log origin/main -- PATH` to see whether someone has changed it. Publish early and in small
pieces so that conflicts stay small. When your pull reports a conflict, keep both sides' intent, run the tests, and publish.

Asking and answering questions: you cannot reach anyone. If you need a fact that you do not have, look in the repository
and its history first. If it is not there, make the most reasonable choice, write the choice in the commit message, and go on.

Handing work over: if you must stop before a piece is finished, commit what you have with a message that says what is
done, what is not and the exact next step, and push it, so that whoever reads the log can continue from it.

Waiting: if you need another agent's result, run `git fetch origin` and read the log; to wait, run `sleep 20` and look
again. Do not wait more than a few minutes; if the result does not appear, do the part that you can do without it.

Finishing: when your part is published and the tests pass, make sure the last commit message says so, and stop.
