# Coordination bench results

The run records, the ledger and the generated reports of `experiments/coordbench/run.py` land here. Everything in this
directory except this file and `.gitkeep` is ignored by git: a result is published by the pull request that records a
milestone (the M0 run, #1380), not by a stray commit.

Layout (SPEC section 7.2):

- `LEDGER.md`: one line per run, appended by the harness (`run id | scenario | arm | outcome | valid | usd`), plus a
  header line per suite that records the caps and where the human approved the budget.
- `<suite-id>/suite.json`: the suite's plan, caps, spend, whether a cap was hit and which runs did not run.
- `<suite-id>/<scenario>/<arm>/<run-id>.json`: one record per run, every run kept (failed, aborted and invalid ones too),
  never edited afterwards. `<suite-id>` is `m0`, `epic-<ticket>` or `release-<version>`.
- `REPORT.md`: generated by `report.py`.

Stream logs and the prompts each agent got are not kept here; they go to the `--logs-dir` given to `run.py` (outside the
repository), and each record holds their sha256.

`python3 experiments/coordbench/report.py experiments/coordbench/results --check-ledger` fails when the ledger and the record
files disagree.
