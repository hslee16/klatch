An experiment harness repeats a scenario N times and reports variance (#243; no schema change; 2026-11-20). Runs four to nine of the two-agent experiments were single runs of a stochastic system, so a difference of a few turns or cents between variants was within noise. `experiments/variance/repeat.py --runs N [--json FILE] -- COMMAND...` runs a scenario command N times, reads one JSON result from the last line of its stdout each time, and prints mean, sample standard deviation, min and max of turns, tokens, cost and duration per agent, plus a count of each outcome (a failed run is counted, not dropped). The result is either a `claude -p --output-format json` object (read as one agent; tokens add input, output and cache tokens) or `{"agents": {name: {turns, tokens, cost_usd, duration_s, outcome}}}` for several agents. One run reports `sd n/a` rather than a zero spread. The script starts no agent itself and spends only what the scenario command spends; it is run on demand, never in CI. `experiments/variance/test-repeat.sh` tests it against a fake agent and runs in the gate.

**Not covered:** the part of #243 that records which earlier conclusions held up when rerun needs real agent runs and spending, so it is left to the human (the ticket stays open). The harness runs repeats one after another and has no confidence interval or significance test; with the small N a real run affords, compare the ranges, not only the means.
