The GitHub watcher runs under launchd, installed by the human (#1343; no schema change; 2026-11-22).
Background tasks belong to the Claude Code process and die with it, so the receiver and forwarder are meant to run as LaunchAgents (systemd user units on Linux). `gh-watch install-launchd` only prints the two plists, with absolute paths resolved from the script location and the state dir, `RunAtLoad`, `KeepAlive`, a `ThrottleInterval` and logs in the state dir, together with the `launchctl bootstrap`, `print` and `bootout` commands; an agent never writes into `~/Library/LaunchAgents` and never runs `launchctl bootstrap`.

No plist holds the secret. The receiver reads its mode-0600 secret file. The forwarder job is the reviewed script `proto/scripts/gh-watch-forward`: it refuses a missing or non-0600 secret file, never prints the secret, runs no `gh` command other than the final exec of `gh webhook forward`, and so leaves the secret visible in `ps` to the same user until #1333 is settled. The receiver keeps its read-only guarantee (no `gh` call, no HTTP client). `gh-watch status` adds one read-only `launchctl print` per job label, skipped where `launchctl` is missing, and `nohup` through `gh-watch ensure` stays the fallback.
