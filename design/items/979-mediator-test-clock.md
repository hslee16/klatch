The mediator claims test no longer depends on the wall clock (#979; test only; no schema change).
`the_mediator_leaves_the_claims_exactly_as_they_were` compared two `claims lobby` outputs, and the `N s left` column counts down with real time, so a second boundary between the reads ("600s left" then "599s left") failed the gate at random. The test now compares the two outputs with that column removed, so it still proves the mediator changes no claim, holder or scope. Proven red by putting a 1.1 second pause between the reads (599s against 600s), then green with the column removed and the pause gone.
