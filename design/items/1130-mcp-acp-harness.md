`klatch mcp --stdio` and `klatch acp --stdio` judge a join by the verified harness (#1130; no schema change; 2026-11-21).
`klatch mcp --stdio` and `klatch acp --stdio` now build their session the way `serve --stdio` does (#1115): when the walk up the process tree verified a Claude Code session (`caller.claude_code`, #877), the session carries the Claude Code harness and a `klatch_join` is judged by it. The harness is never read from a request; a typed name, a credential, or no session above the process stays the generic floor. The ACP agent only answers looks today, so no join reaches it; it carries the same evidence so a later write method inherits the rule. This also meets #1003 for the stdio transports: a wire join carries no harness field and needs none, because the edge supplies the evidence it verified.
