The dm adoption scenario measures arms that really differ (#1210; no schema change; 2026-11-21).

The first real runs (#1194) had three flaws, found by the audit under #1183. The text and nudge arms used one binary, so they were one arm; the prompts told the agents "use this binary only" with a command list that had no `dm` and said "ask the lobby", which outranks an unrequested context line; and the stream-json records held only SessionStart hook output, so it was unproven that PostToolUse hooks run under `claude -p`.

`experiments/dm-adoption/run.sh` now picks the binary per arm: `baseline` needs `KLATCH_BASELINE_BIN` (a build from before the dm epic, commit 28219a44), `text` needs `KLATCH_TEXT_BIN` (the dm convention text without the digest nudge, commit b5b063ad, the merge of #1199; the nudge arrived with eb98f45c, #1190), and `nudge` uses `KLATCH_NUDGE_BIN` or else `KLATCH_BIN` (origin/main at or after 935f15b7). The binary has no switch that turns the nudge off, so the text and nudge arms differ by the binary alone; the result line records `binary` and `binary_sha256` so an audit can tell. `private` stays as the told-to-dm control.

The prompts give the same text in every arm but `private`: they say how to call klatch (the binary path) and name only `post`, `read` and `wait`, with no allowed-subcommand list and no lobby anchor. `ask`, `answer` and `dm` are left to the convention text the SessionStart hook injects, which is what the experiment tests.

`--hook-events` adds `--output-format stream-json --verbose --include-hook-events` to each `claude -p` (the flag name is `--include-hook-events` in `claude --help`; it only works with stream-json, and `-p` stream-json needs `--verbose`). The stream is kept as `<name>.stream.jsonl` in the run directory. `metric.py --hook-events NAME=FILE` reports per agent `hook_events` (hook_response events), `hook_post_tool_use` and `nudge_lines` (digest nudge lines found in hook output only, not in model text), and their sum on the exchange entry. A non-zero `hook_post_tool_use` confirms the digest hook runs in headless mode.
