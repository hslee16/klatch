Release steps are scripts with fake-backed tests (#1239, #1240, #1241, #1242, #1249; no schema change; 2026-11-21).
release/rehearse-assemble.sh runs the changelog, DESIGN and RESEARCH assembly and check-versions.sh on a throwaway copy and prints the diff stat and the references that still need renumbering; release/release-notes.sh fills RELEASE-NOTES.template.md from SECURITY.md "What is not protected" and the open audit gap rows; release/bump-formula.sh rewrites the tap formula from SHA256SUMS and prints a patch and REST commands but never pushes; release/rollback-rehearsal.sh prints the yank, deprecate and revert commands and runs the reversible ones only with --execute, tokens in the environment and a pre-release version; release/verify-published.sh checks PyPI, npm, crates.io, the GitHub release, the tap formula and a clean install from the public side.

Every script is bash 3.2 plus python3 standard library, runs no network call in its test (fake gh, curl, npm, pip, brew), prints no token and has no sleep. The scripts that could publish (bump-formula, rollback-rehearsal) are print-only by default and never call gh or git themselves except the explicit --execute of the rollback rehearsal. RELEASING.md describes each in its section instead of repeating the steps.
