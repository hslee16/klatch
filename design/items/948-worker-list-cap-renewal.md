The worker listing shows the credential cap and last renewal (#948; no schema change; 2026-11-20).
`klatch worker list` now prints, beside the expiry, how many seconds remain to the hard cap that renewal never passes and when the credential was last renewed on use, so a launcher can see how long a busy credential can still live. `CredentialInfo` gains `cap` (0 for a credential from before renewal, which is never renewed) and `last_renewed`. The last renewal is read from the `renew-credential` audit entries, newest first, ignoring entries older than the credential's issue; the listing scans the latest 10000 audit entries, so a renewal older than that shows as never. No operation is added: it is still `admin_credentials`, guarded as before.
