The pty test harness drains the terminal after the child exits (#1298, #1301; no schema change; 2026-11-22).
The admin_proof tests failed intermittently under load, one test per run, with an empty terminal text. The cause was in the test harness (proto/klatch/tests/common/pty.rs), not the product: the harness closed its own copy of the slave side of the pseudo-terminal at once, so when the child exited the last slave descriptor closed while the child's final output could still be on its way to the master, and on macOS that output is lost under load. The harness then saw end of file and an empty text, and the assertion on the prompt text failed.

The harness now keeps its slave descriptors open until the run is over. The master never hangs up, the end of a run is the child's exit, and the output is then drained to the end. No sleep and no timing luck is involved. Product code is unchanged. Measured with eight parallel copies of the admin_proof binary under load: before, 7 of 8 first runs failed (9 test failures, always with empty text); after, 24 of 24 full runs passed.
