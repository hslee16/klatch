Recipes for the launchers klatch itself ships, checked by a doc test (#126, #414; no schema change; 2026-11-21).
`clients/recipes/own-launchers.md` gives a recipe for a plain script launcher (the CI demo), a Makefile launcher, the team launcher, the integrator and the ask supervisor. **Why:** the orchestrator recipes of #414 need a person with desktop tools, but the launcher pattern is the same under all of them, so a reader gets checked recipes now. **What is checked** (`clients/recipes/test_own_launchers_doc.py`): each klatch command in the Makefile is one `launcher-demo.sh` runs in CI, `make -n` of every target runs nothing, every script and flag named is in that script's header, the third-party tools stay `not run`. **Limit:** the Makefile was not run against the real binary, and the page says so.
