Doctor checks the trust of a klatch hook in a project .codex/hooks.json (#590; no schema change; 2026-11-24).
The last open part of #590 was where Codex keys trust for a hook in a project `.codex/hooks.json`. RESEARCH-NOTES 49.9 observed it with `codex app-server` `hooks/list` in a temp `CODEX_HOME` (Codex 0.147.0, no login, no model call): the key is `<project dir>/.codex/hooks.json:<event_snake>:<n>:<m>`, the record is the same `[hooks.state."<key>"]` `trusted_hash` in the user `config.toml`, and the hash rule is the one already used for user hooks. The project layer loads only when `config.toml` has `[projects."<dir>"]` with `trust_level = "trusted"`; otherwise Codex lists no hook, so an untrusted project and a project with no hooks look the same through Codex.

`klatch doctor` therefore judges a klatch hook in the project file like a user hook (ok, not trusted, changed since trusted, with the unchanged fix text) when the config records the project as trusted, as given or with symlinks resolved, and the `hooks.json` key is looked up under the same two spellings. When the project is not recorded as trusted, doctor keeps the line "codex hooks (project): ... cannot be checked" and now says why (the project is not recorded as trusted in the config) instead of "where it records trust is not verified", which was true before 49.9 and is false now. That reworded clause is the only existing doctor text that changed; no golden pins it. Every other doctor line is byte for byte the same.

Limits, all noted in 49.9: the check reads the `.codex/hooks.json` of the directory doctor runs in (Codex also walks up to the git root); a trust entry on a directory above the project is not honoured (not observed); a non-git project and Codex versions other than 0.147.0 were not observed; whether a trusted project hook runs in `codex exec` needs a login and was not tried. The check reads the Codex config read only, makes no network call, never runs Codex, and never writes a trust record. The installer (#341, #782) is not part of this item.
