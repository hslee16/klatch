Opt-in hosted judge in `klatch judge run` (#960; no schema change; 2026-11-20).
The default judge is and stays the local rules judge. An operator can additionally turn on a hosted judge for our own rooms and evaluation with `klatch judge run --hosted-judge <model> --hosted-ceiling <label>` (a Claude model reached through the operator's own `claude` binary). Both flags are required together and neither has a default, so without them nothing in the command sends text anywhere. It is not the product judge and is not advertised or enabled as one; the Sonnet judge of #942 is the model our own evaluation used, nothing more.

    Operators: turning it on SENDS ROOM TEXT to an outside service (the model provider, through your `claude` login or `ANTHROPIC_API_KEY` in your environment). The command prints a notice saying so at start. No key is read from configuration or stored by klatch.

    What is sent: only text of an item whose source label is strictly below `--hosted-ceiling`; an item at or above it, or with a label not in the chain, is never sent and stays queued. The scrub list is never sent. The transport is the quarantined reviewer of D4, the same approach as `klatch-bench`'s `claude:<model>` judge: one message on stdin inside a fence it cannot close, no tools, no MCP, no hooks or setting sources, no saved session, a dollar cap per call, a fresh private working directory and an allow-listed environment.

    Composition: `Narrowed(rules, BelowCeiling(Breaker(ClaudeJudge)))`. The rules judge runs first and a rules deny stands, so the hosted judge never sees text the rules denied. `BelowCeiling` sits outside `Breaker` so the normal traffic above the ceiling is not counted as hosted failures. Any transport failure, unparsable reply or non-zero exit is a `Defer`, three in a row open the breaker for the rest of the loop, and a failure is never an allow. A verdict is still data: the gateway checks the floors again when a crossing is released.

    Not done: the stored ceiling setter and the onboarding question (#870), so the ceiling is a command-line flag for now; the uncertain-band hand-off to the reviewer, which is not specified (ticketed); and `klatch-bench` still carries its own copy of the transport, to be pointed at the shared one (ticketed).
