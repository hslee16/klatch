The assembly rehearsal can also run the checks that assembling breaks (#1286; release tooling only; no schema change; 2026-11-21).
Assembling the fragments into DESIGN.md broke four things the rehearsal did not run: a test that read a design fragment by file name, DESIGN items quoting phrases that `release_scope_docs` forbids, a script test that pinned the old version, and `THIRD-PARTY-LICENSES.txt`, which carries the workspace version. `release/rehearse-assemble.sh --check-tests` now runs, on the throwaway copy after the assembly, a version check of the notices file (the cheap part of `proto/check-notices.sh`, which needs cargo-about), `cargo test -p klatch --test release_scope_docs`, `cargo test -p klatch --lib negotiate` and every `release/test-*.sh` except the rehearsal's own test. The flag is optional so the default rehearsal stays fast. `REHEARSE_CARGO` and `REHEARSE_TARGET_DIR` override cargo and its target directory (default: the real tree's `proto/target`, so there is no cold build); the tests use a fake cargo. RELEASING.md section 1 describes the flag.
