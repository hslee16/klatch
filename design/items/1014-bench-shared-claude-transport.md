The bench's claude judge uses the shared transport (#1014; no schema change; 2026-11-20).
`klatch-bench`'s `claude:<model>` judge no longer carries its own copy of the headless `claude -p` transport, prompt, isolation flags, environment allow-list and reply parser. They live once in `klatch::gateway` (`Session`, `parse_reply`, `run_command`), next to the opt-in hosted judge of #960, so the two cannot drift. The bench wraps the shared session and adds only what it measures: the scrub list appended to the system prompt, the confidence, token and cost accounting, and a runner that starts the binary `--claude` names. The production judge still never sends the scrub list, still starts `claude` by name only, and its opt-in, ceiling and defer-on-failure behaviour are unchanged. The bench's measured behaviour (prompt, command line, environment, `--budget-usd`, results format) is pinned by a golden test captured from the old transport before it was removed.
