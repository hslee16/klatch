Renumbering the references after assembly (#1244; no schema change; 2026-11-21).
After `design-fragments.sh assemble` and `research-fragments.sh assemble` the fragments have numbers, but text across the tree still says "the design item for #T" or "the research note for #T". `release/renumber-refs.sh MAPFILE [root]` rewrites them from the summary lines the two assemble steps print on stderr (`item N <- #T (file)` and `section N <- #T (file)`; other lines are ignored). **Form:** "design item for #T" becomes "design item N"; "research note for #T" becomes "research note section N". **Scope:** every text file under the root except `.git`, `target`, `node_modules`, `release/` (its tests carry fixtures) and `*.jsonl` (data such as the judge corpus, whose text must not change); the literal placeholder "#NNN" is never a reference. **Loud failure:** the whole tree is scanned first; if any referenced ticket has no number in the map (for example a reference to an item that is not a fragment), the tickets are named on stderr, the exit status is 1 and nothing is changed. **Output:** one line per change, `file:line: old -> new`. A second run finds nothing and exits 0. **In the rehearsal:** `release/rehearse-assemble.sh` captures the assemble summaries, runs the renumbering on the copy before the changelog collect (so the entries carry the numbers), and reports zero remaining placeholders; on the tree at the time of writing it renumbers the references with none left over. **Tests:** `release/test-renumber-refs.sh` (fixture with design and research references, exclusions, a placeholder, a second run, a reference with no item that must fail and change nothing, a missing map) and the extended `release/test-rehearse-assemble.sh`; both were written before the script and failed first because it did not exist. The gate runs the new test.
