The rollback rehearsal never runs npm, and the assembly rehearsal builds fresh (#1295, #1292; no schema change; 2026-11-22). `npm deprecate` answers EOTP on an account with two-factor authentication, so `release/rollback-rehearsal.sh --execute` cannot run it unattended; the script runs the GitHub and crates.io steps only and prints the two npm commands for the owner to run in a logged-in terminal, where npm asks for the one-time password itself. A one-time password is never read from the environment or an argument, and `NPM_TOKEN` is no longer used. A crates.io yank needs a token with the `yank-version` scope even with trusted publishing, which covers publishing only.

`release/rehearse-assemble.sh --check-tests` uses a fresh cargo target directory per run (removed on exit) unless `REHEARSE_TARGET_DIR` is set: cargo bakes `CARGO_MANIFEST_DIR` into test binaries, so a shared target directory ran a binary built for the previous, deleted copy. The price is a full build each run.
