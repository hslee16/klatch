The one-need-info-per-ask check reads by prefix at any depth (#980; no schema change; 2026-11-20).
`check_need_info` looked for the facilitator's earlier need-info for an ask in `tail(room, 0, 5000)`, which returns the oldest 5000 messages of the DM room, so in a room past 5000 messages a repeat need-info went unseen. It now uses `MessageStore::words(room, ["need-info #"])`, as the board and open asks do (#731). The lobby field-repeat check, which matches another member's text anywhere in a message, still reads a 5000-message window; it needs a query the prefix form cannot give and is tracked in #997.
