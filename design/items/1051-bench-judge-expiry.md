The bench covers the hosted judge as releaser and credential expiry on a live wire (#1051; no schema change; 2026-11-21).
A test build (`--features test-clock`) now also reads `KLATCH_NOW_FILE`, a file holding the time in unix seconds, at every call of `member::now`; it wins over `KLATCH_NOW`, and a real build ignores both. The bench `World` writes its clock to `klatch-now` in the world's home on `set_clock` and `advance` and hands the path to every command, so a process that is already running (`serve --stdio`) sees the clock move.

`World::judge_with_fake_claude` runs `klatch judge run --once --hosted-judge sonnet --hosted-ceiling <label>` with a `claude` that is a local shell script printing a fixed reply. `PATH` holds only that script's directory and `/usr/bin:/bin`, so no real `claude` is ever found: no model is called, no credential is used and no text leaves the machine. The scenario `the_release_audit_names_the_judge_when_the_hosted_judge_allows` shows that a ceiling at or below the source label sends nothing and releases nothing, and that an allow under a higher ceiling releases the crossing with the audit naming `judge` as the releaser. The scenario `a_live_wire_is_refused_once_its_credential_expires_under_it` starts a worker's `serve --stdio` on a 60 second idle credential, serves one call, advances the world's clock by 120 seconds, and expects the next call on the same process to be refused as expired.
