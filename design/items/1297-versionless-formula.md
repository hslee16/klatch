The Homebrew formula carries no version line (#1297; no schema change; 2026-11-22). `brew audit --strict`, which the tap CI runs, fails a formula whose `version "..."` repeats the version scanned from its URL, so the formula has none and its version is whatever the four release URLs carry. `release/bump-formula.sh` removes any existing line and checks that the four URLs carry the tag and the version; `release/check-versions.sh` and `release/verify-published.sh` take the version from the URLs when there is no line (and still fail when a line, if present, or a URL disagrees); `release/compare-formula.sh` ignores a version line on either side, so a line on one side only is not drift when the URLs agree.

The rule stays single-sourced: the tag and archive names come from `release/pep440.sh`, and the staged copy `release/homebrew/klatch.rb` equals the tap formula apart from URLs and hashes. The `--rehearse` path runs `brew audit --strict --new` on the bumped formula, so the failure that appeared on release day is found before it.
