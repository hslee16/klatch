`klatch serve --stdio` judges a join by the verified harness (#1115; no schema change; 2026-11-21).
A wire `join` over `klatch serve --stdio` was always the generic floor, so a member serving from a verified Claude Code session could not join a room with a `room-require` harness requirement. The session now carries the harness the process tree verified (the same `claude_code` evidence a CLI command passes, #877), and a `join` is judged by it. The harness is never read from a request. A typed name, a credential, no session above the process, and an ssh forced command (a remote peer, where this machine's process tree says nothing) all stay the generic floor.
