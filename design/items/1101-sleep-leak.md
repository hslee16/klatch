Team watchdog sleeps and the gate leak check
The team launcher's wall-clock watchdog is a subshell running `/bin/sleep $TEAM_MAX_SECONDS` (default 3600). When a worker finished, the runner killed only the subshell, and `team stop` killed only the runner's direct children, so the sleep was orphaned (ppid 1) and lived up to an hour. A gate run left about 50 of them; 2,238 once exhausted the process limit (#1101). Both paths now kill the sleep first. `proto/scripts/test-team.sh` runs with a sentinel `TEAM_MAX_SECONDS=3602` and fails if any such sleep outlives the run, and `proto/scripts/gate` counts `/bin/sleep 3600` processes before and after and fails if the run added any.
