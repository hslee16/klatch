The coordination bench is specified before any run (#1363; epic #1362; no schema change; 2026-11-22).
`experiments/coordbench/SPEC.md` fixes how klatch is compared with agents that coordinate without it: five arms (B0 shared repository only, B1 native Claude Code messaging plus a task board, K1 klatch with convention text only, K2 klatch as shipped, K3 klatch with integrator and supervisor roles), ten scenarios (S1 to S10) each with a task, a small deterministic fixture, a hidden checker and failure modes, precise metrics taken from git, the store and the agent stream rather than self-reports, and statistical rules (N per arm, medians and spread, Fisher exact for rates, Mann-Whitney U and a bootstrap interval for continuous measures, an exploratory label under N of 5, every run kept).

The arm prompts are written to one outline and checked for equal length so the klatch arms do not get better instructions than the baselines; the drafts in `experiments/coordbench/arms/` stay drafts until the B1 ticket (#1365) reviews them. The thresholds section is empty by rule: targets are filled only from the measured B0 and B1 baseline of the M0 run (#1380), never invented. Real-agent runs need the human's budget approval first; this item and the specification run no agent and spend nothing.
