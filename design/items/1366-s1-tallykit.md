Scenario S1 of the coordination bench is built: a four-agent build on the tallykit fixture, with a hidden checker and git-history metrics (#1366; no schema change; 2026-11-22).
Epic #1362 needs a throughput and cost scenario close to how klatch is used, and S1 is it: four agents, four tickets of two modules each on F1 `tallykit` (a standard library Python package of eight independent modules with stubs, docstring contracts and weak visible tests), plus a shared registry (`tallykit/__init__.py`) and `CHANGELOG.md` that every ticket edits at the end, so a real merge conflict is possible while the work is otherwise disjoint. The fixture's `reference/` solution is never in a checkout; the hidden checker lives in `checks/tallykit/`, loads each module by file and runs seeded property tests against independent oracles, so a broken registry cannot hide a good module and a visible-test pass is not enough. It prints units completed (0 to 8), the structural checks (registry, changelog, conflict markers, visible tests), a merge state (clean, conflicts left, tests broken) and contribution by git author.

The scenario file `scenarios/s1.json` holds arms B0 B1 K1 K2 K3 (K3 not at M0), N per arm (10 at M0, 3 quick), the spend caps from SPEC 8.1 and the unit-to-path map the harness had left null (ticket #1399 item 1). With it the harness fills two fields from git history over the origin and every agent clone: `duplicate_work` (modules changed by commits of more than one agent) and `overwrites` (registry or changelog lines committed somewhere and absent from the final main). Each agent now commits under its own name, so authorship means something; the detail goes under `scenario_metrics` in the record. The checker is validated on the reference (8 of 8) and on a missing module, a broken module, a conflicted merge, a lost registry entry, a lost changelog line and a duplicated one, and the metrics are tested through the whole harness with fake agents that solve it, collide, overwrite, duplicate and give up. Nothing here ran a model or spent money; the real run, the human's budget approval and the arms review (#1365) remain, and the ticket closes when M0 results exist.
