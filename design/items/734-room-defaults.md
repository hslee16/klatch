`board`, `asks`, `claims` and `history` with no room list the caller's rooms, as `who` does (#734, #227; no schema or wire change; 2026-11-18).
The default is for the read-only commands that move no cursor, and it is conservative on purpose. **Format:** a `[room]` header per joined room (the order `who` uses, `rooms()`), then that room's output as with a room; a caller that joined none gets the line `you have not joined any room (klatch join <room>)`. With a room the output is unchanged and has no header. One helper (`for_rooms` in `commands.rs`) now serves `who` too. **Only the rooms the caller joined:** a room it has not joined is never listed, so the default reveals nothing a named room would not. **Left out, with the reason:** `read` consumes (it advances the caller's cursor), so a default over every room would mark unread what the caller never saw; `receipt ROOM SEQ` names a message, and a seq means nothing without its room; `history --since N` is a seq of one room, so with no room it is refused with the form that works. `history` with no room shows the newest 20 of each room under the history byte budget per room, so a caller with many rooms can see a lot of output; `--last N` narrows every room. Not built: a default for `tasks` (the same shape, not asked), a combined view that merges rooms by time. Tests (written first; red as usage errors for a missing room): `tests/room_defaults.rs`, including that `history` leaves the unread messages unread.
