The mediator proposes a dm for a long two-member exchange (#1191; part of #1183; no schema change; 2026-11-21).
In installs where hook digests are not shown (headless) but a mediator runs, two members can still hold a long exchange in a shared room. **The event:** `klatch stuck ROOM` and the wire method `stuck` gain a fifth kind, `long_exchange` (`room`, `members` sorted by name, `messages`; key `long_exchange:ROOM:A,B`). It is derived on every call and stored nowhere, with the same guard as the other kinds. It is the newest run of messages sent by only two members, counted by `domain::exchange_run`, the one function the digest nudge (#1190) also uses, over the room's newest `DM_NUDGE_WINDOW` (64) messages; it needs a run of `DM_NUDGE_MESSAGES` (4) or more, a room of three or more members, both members still in the room, and no dm between them (`dm_pair`). A third member's message ends the run. **The proposal:** one fixed line, `mediator proposal: @A and @B have exchanged N messages in ROOM. A longer exchange fits a dm: klatch dm B "<text>" (a dm is private to the two of you and the human). A proposal only: nothing is cancelled or released for anyone.` It holds no message text (the event has no text field), the names are validated like every other mediator line, a pair that includes the mediator is skipped, and no room is created and nobody is invited. **Once:** the key is per room and pair, so within a run the mediator proposes once while the exchange stands. Its own post is a third sender and ends the run, so the case stops standing; a later new exchange between the pair, with no dm yet, is proposed on again, as for any case that ends and returns. **Off unless run:** nothing posts unless `klatch mediator` runs; the only change for anyone else is one more line from `klatch stuck`. **Limits and options:** the count N in the line changes as the exchange grows, so a restarted mediator (which recognises its earlier posts by exact text) may repeat the line for a standing exchange once; the line names the later name of the pair for `klatch dm`, and which member should open the dm is not decided by klatch. Not covered: a three-way thread, and an exchange that already moved to an `ask-N` room.
