Package contents are asserted by one script (#1243; release tooling only; no schema change; 2026-11-21).
release/check-package-contents.sh takes a wheel or an npm tarball. A wheel must hold the klatch and klatch-server commands (both executable), LICENSE and THIRD-PARTY-LICENSES.txt; an npm tarball must hold dist/, README.md, LICENSE and package.json and nothing else, so no binary. build-release.yml calls it for the wheels (replacing the inline check of #1236) and, new here, for the npm tarball after npm pack, both inside existing jobs. The human can run it on downloaded artifacts. release/test-check-package-contents.sh checks it on fixture wheels and tarballs (a good one, one missing a file, a non-executable server, a binary or stray file in npm) and runs in the CI scripts step. Release archives stay checked by release/check-archive.sh.
