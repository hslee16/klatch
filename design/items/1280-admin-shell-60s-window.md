The admin shell unlock window defaults to 60 seconds, and the SECURITY text names terminal input injection (#1280, #1276; no schema change; 2026-11-22).
The unlock window of `klatch admin shell` (#1233) defaulted to 5 minutes. A program that shares the terminal can try to inject keystrokes (TIOCSTI, where the OS allows it) while the shell is open and run admin and launcher commands without a prompt, so the human decided on 2026-11-22 to shorten the default to 60 seconds. `klatch admin unlock-window` still sets 10 to 1800 seconds and `--off` puts the default back; an install that stored its own length keeps it.

SECURITY.md now says that an open shell on a shared terminal is exposed to injected keystrokes, and does not probe for TIOCSTI. It also says that a worker or agent started from the human terminal can cause the prompt to appear but cannot answer it, that the prompt names the exact command and the human decides, and that a program hosting or relaying the whole terminal is the documented residual (#1276, documentation only).
