Variance harness gets a spend cap, a per-run timeout and isolated stores (#243; no schema change; 2026-11-21).
experiments/variance/repeat.py already repeated a scenario N times and printed mean, sd, min and max. It now runs every repeat with a fresh empty KLATCH_HOME and KLATCH_KEY_DIR under a temp dir (removed afterwards), so no run touches ~/.klatch or the Keychain; `--timeout SECONDS` kills a hung run and its process group and counts it as a failure; `--max-cost USD` stops the loop once total cost reaches the cap (exit 3, and a result without a cost under a cap fails loudly); a crashed, timed-out or unparseable run is counted instead of aborting the loop; the report prints `failures: K of N`. Tests drive a fake scenario only, so no real claude runs. Rerunning earlier experiments with real agents stays with the human, so #243 stays open.
